# Vijay Paderthi Website - Color Theme Reference

## 🎨 Primary Color Palette

### Blue Theme (Main Brand Colors)
- **Primary Blue**: `blue-600` (#2563eb) - Main CTAs, links
- **Primary Blue Hover**: `blue-700` (#1d4ed8) - Button hovers
- **Light Blue**: `blue-50` (#eff6ff) - Backgrounds
- **Medium Blue**: `blue-100` (#dbeafe) - Secondary backgrounds
- **Blue Text**: `blue-600` (#2563eb) - Colored text
- **Dark Blue**: `blue-900` (#1e3a8a) - Headers, hero sections

### Supporting Colors
- **Indigo**: `indigo-500` to `indigo-900` - Accent colors, gradients
- **White**: `white` (#ffffff) - Main background
- **Gray Scale**: 
  - `gray-50` (#f9fafb) - Light backgrounds
  - `gray-600` (#4b5563) - Body text
  - `gray-700` (#374151) - Dark text
  - `gray-900` (#111827) - Headings

### Accent Colors (Use Sparingly)
- **Orange**: `orange-500` (#f97316) - Amazon/external links only
- **Green**: `green-100`/`green-700` - Success states, positive actions

## 🚫 Colors to AVOID
- **Red** - Unless for errors
- **Purple** - Only for Book 3 "Coming Soon" sections
- **Yellow** - Unless for warnings
- **Random colors** - Stick to the blue theme

## ✅ Usage Guidelines

### Buttons
- **Primary Action**: `bg-blue-600 hover:bg-blue-700 text-white`
- **Secondary Action**: `border-blue-600 text-blue-600 hover:bg-blue-50`
- **External Links**: `bg-orange-500 hover:bg-orange-600 text-white`

### Backgrounds
- **Hero Sections**: `bg-gradient-to-r from-blue-900 via-blue-800 to-indigo-900`
- **Content Sections**: `bg-blue-50` or `bg-white`
- **Cards/Boxes**: `bg-white` with `border-blue-200`

### Text
- **Headings**: `text-gray-900`
- **Body**: `text-gray-600` or `text-gray-700`
- **Links**: `text-blue-600 hover:text-blue-800`
- **Accent Text**: `text-blue-600`

## 📝 Notes
- Always test color combinations for accessibility
- Maintain contrast ratios of at least 4.5:1
- Blue theme represents professionalism and trust
- Consistent use builds brand recognition
